4. 对话处理流程（时序）

sequenceDiagram
    participant U as 用户
    participant APP as app.py
    participant CORE as core.py
    participant EMO as MiruEmotion
    participant CARE as CareEngine
    participant PRE as Memory Pre-retrieval
    participant CTX as Context Builder
    participant AGENT as Agent Loop (prompt.py)
    participant LLM as LLM API
    participant TOOLS as Tools (3个)
    participant SLEEP as Sleep-time Agent
    participant STOR as storage.py

    U->>APP: POST /api/chat {text, image?}
    APP->>CORE: receive_chat_message(text, image)
    CORE->>STOR: append_chat_message(user_msg)
    CORE->>CARE: on_user_message() 重置自适应冷却
    CORE->>SLEEP: enqueue("user", text)
    Note over CORE: 1.5s quiet period (等用户打完字)

    CORE->>PRE: 语义预检索(user_text)
    PRE->>LLM: 轻量LLM分析 → 匹配index
    LLM-->>PRE: 相关文件路径
    PRE->>PRE: 加载归档文件

    CORE->>CTX: _build_chat_context()
    Note over CTX: 核心记忆 XML
归档索引 (100行)
活跃承诺
用户情绪感知
Miru心情 + 关系阶段
+ 预检索文件

    CORE->>AGENT: call_chat_agent(context, history, text, tools)

    loop Tool-use Loop (max 8轮)
        AGENT->>LLM: system_prompt + context + messages + tools
        LLM-->>AGENT: response (text or tool_use)
        opt 如果 LLM 调用工具
            AGENT->>TOOLS: execute(args)
            TOOLS-->>AGENT: result
        end
    end

    AGENT-->>CORE: {reply, tool_calls}
    CORE->>STOR: append_chat_message(reply_msg)
    CORE->>SLEEP: enqueue("assistant", reply)

    CORE->>EMO: update(trigger, reason) 基于缺席时长
    CORE->>EMO: record_interaction()

    CORE-->>APP: reply
    APP-->>U: SSE / JSON response

    Note over SLEEP: 3min后无新消息 → flush
    SLEEP->>LLM: 分析对话 → 记忆 + 情绪更新
    LLM-->>SLEEP: {core_memory_ops, archival_ops,
index_updates, emotion_update}
    SLEEP->>SLEEP: 应用核心记忆 + 归档更新
    SLEEP->>EMO: update(trigger, reason) 精准情绪评估

5. 后台系统运行时序

sequenceDiagram
    participant SCREEN as 用户屏幕
    participant SO as ScreenObserver
    participant VLM as VLM API
    participant SUM as Summarizer
    participant MEM as memory/*.md
    participant EMO as MiruEmotion
    participant CARE as CareEngine
    participant LLM as LLM API
    participant CHAT as Chat UI

    loop 每30秒
        SO->>SCREEN: 截取缩略图
        SO->>SO: 像素差异比较
        alt 变化 > 15% & VLM冷却期已过(5min)
            SO->>VLM: 发送截屏
            VLM-->>SO: "3|用户在VS Code编辑Python文件"
            SO->>SO: 去重检查 (关键词重叠 > 70%?)
            alt 非重复 & 任何分数
                SO->>SUM: enqueue("observation", text)
            end
            alt 显著性 >= 3
                SO->>CARE: add_observation(text)
            end
            opt 深夜时段 (23:00-05:00)
                SO->>EMO: update("late_night_user")
            end
        end
    end

    Note over SUM: 3min防抖 / 12条上限
    SUM->>LLM: 批量消息 + 现有文件 → 分析
    LLM-->>SUM: {operations, index_updates}
    SUM->>MEM: 写入journal/、people/等
    SUM->>MEM: 更新index.md

    loop 每15分钟
        CARE->>CARE: 检查缺席时长
        opt 缺席 >= 3h
            CARE->>EMO: update("absence_short")
        end
        opt 缺席 >= 12h
            CARE->>EMO: update("absence_long")
        end
        CARE->>MEM: 读取 commitments/active.md
        CARE->>MEM: 读取 journal/today.md
        CARE->>MEM: 读取 patterns/*.md
        CARE->>EMO: 获取 Miru 当前心情
        CARE->>LLM: 评估6条关怀规则 + Miru心情
        alt should_send = true
            LLM-->>CARE: 角色语气的关怀消息
            CARE->>EMO: update(触发类型)
            CARE->>CHAT: 推送关怀消息
            Note over CARE: 连续未回应 >= 2次
→ 冷却从30min拉长到1h
        end
    end
