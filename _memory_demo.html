用户一句话进来,后台发生了什么

1
立刻 (秒级) · core.chat_with_companion()
调主对话 LLM 回复用户 → 同时把消息塞进 sleep_agent 队列 (in-memory, per user)
↓ 防抖 3 分钟 / 队列满 12 条
2
SleepAgent 切片 (1 次 LLM) · call_sleep_agent_v2
看一批消息,丢弃寒暄/问句 → 输出 0-3 个 fragment、可选 human/persona 块更新、完成的承诺标题
↓ 每个 fragment 独立异步
3
4-Pass Router (最多 4 次 LLM) · route_and_write()
Pass 1 分类 domain → Pass 2 match/new slot → Pass 3 (仅 new) 设计元数据 → Pass 4 SlotEditor 重写整段 body
↓ 原子写入
4
落盘 + 推送
覆写 main.md · 更新 _slots/<domain>.json · 追加 revisions.jsonl · 记 daily_writes.json · SSE 推 memory_changed → 前端卡片自动刷新
★ 截屏路径并行: VLM observation → 直接进 4-pass router (不经 SleepAgent), source 标 screenshot
★ Identity 路径独立: 设置页改姓名 → cascade_identity() 直接合成 body 写 self/identity, 不走 router
★ Pass 4 关键: 看到完整旧 body + 新输入, 整合 + 压缩重写, 不是 append
