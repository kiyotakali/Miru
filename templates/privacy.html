隐私声明

最近更新：2026-04-15

我们收集什么

Miru 是一只住在你电脑或手机里的 AI 陪伴。为了完成「记住你说过的话」「在你熬夜时担心你」这些功能，我们会在你主动授权的前提下收集：

  • 聊天记录：你和 Miru 的对话，连同时间戳。
  • 屏幕截图（仅当你开启自动截屏功能时）：截图不会上传到 VPS 保存，只会实时送给 VLM 提取一段文字描述，截图本身在读取后立即删除。
  • 你主动上传的图片：保存在 data/users/<你的 ID>/uploads/，仅用于对应卡片的展示。
  • 设备心跳：最近一次连接时间、设备名、平台（Mac/Windows/Android/iOS）。
  • 你的作息活动时间戳（不含内容）：仅来自截图时间戳与聊天时间戳，用于推断你的作息节律——决定 Miru 何时主动陪你、何时保持安静。
我们不会收集你的位置、通讯录、通话记录、浏览器历史，也不会读取系统里其它应用的内容。

数据保存在哪里

所有数据只保存在当前服务器的 per-user 目录：

  • Web/APK 用户：保存在 Miru 官方 VPS（位于境外）的你的专属目录内，路径以你的 user_id 命名，其他用户无权访问。
  • Mac DMG 用户（客户端模式）：保存在你本机 ~/Library/Application Support/Miru/data/，只在你的设备里。

我们不会把你的数据卖给任何第三方。我们也不在除了官方 VPS 之外的任何地方保存备份。

我们会调用哪些第三方

Miru 依赖少量外部 API 才能理解内容：

  • VLM 大模型（由后端运维配置的第三方 LLM 服务商）：用于分析聊天、截图、生成回复。每次调用是无状态的，模型服务商不保留我们的 prompt（据其隐私政策）。
  • Web Push 服务（浏览器各自的 push 端点，如 FCM）：仅用于发送 Miru 给你的消息提醒，不会包含内容本身。

我们不使用任何统计分析（Google Analytics 等）、崩溃追踪（Sentry 等）、或广告 SDK。

你能做什么

导出你的全部数据

在 App 设置 → 隐私中点击 「导出我的数据」，会下载一个 JSON 文件，包含你账号下全部文本记录（聊天、卡片、记忆、情绪日志、模型设置等）。

删除你的账号

在 App 设置 → 隐私中点击 「删除我的账号」，输入二次确认后：

  • 你的 user_id 会立即从服务器用户表中移除。
  • 你的 data/users/<你的 ID>/ 目录会被递归删除，包括聊天、卡片、上传的图片、记忆、情绪日志、Live2D 个性化、全部本地缓存。
  • 你当前使用的邀请码会被标记为「已吊销」，无法再次登录。
  • 我们只保留一条审计日志（不含任何内容），用于排查滥用：{user_id, invitation_code, created_at, deleted_at}。
删除操作不可撤销。如果想保留数据副本，请先导出再删除。

撤回截屏权限

随时在 App 设置 → 自动截屏处关闭开关；Mac DMG 还可在「系统设置 → 屏幕录制」里撤销权限，APK 则在「系统设置 → 应用 → Miru → 权限」处。
