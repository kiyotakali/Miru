Miru

FIRST RUN

Miru 要住在哪里？

你可以让她住在自己的私有服务器里，让多台设备看到同一个 Miru；也可以先只在这台电脑上使用，所有数据都留在本机。

只在这台电脑使用

让 Miru 住在这台电脑

本地模式会在这台电脑上创建一个本地账号。聊天、记忆和 API Key 都只写入本机数据目录；不能多设备同步。

多设备同步使用

你已经有 Miru 邀请码了吗？

已有账号就直接输入长邀请码；还没有账号，可以使用官方服务器，或者让这台电脑帮你在自己的服务器上创建一个新的 Miru。

输入邀请码

让 Miru 回到你身边

这里必须使用完整长邀请码。短码无法登录，请确认已经完整复制。

创建新账号

选择一台服务器

不管是官方服务器还是你自己的服务器，最后都会得到同一种长邀请码，Mac、Windows 和 Android 都用它登录。

官方服务器

官方开通正在准备中

现在如果你已经有邀请码，可以直接登录；如果你有自己的云服务器，也可以先在自己的服务器上创建 Miru。

自有服务器

在你的服务器上创建 Miru

自动安装 Docker 目前支持 Ubuntu / Debian；其他 Linux 请先安装 Docker 和 Docker Compose。先从 Miru 发布页下载服务包，再在这里选择它；创建完成后，Mac、Windows 和 Android 都用同一个长邀请码登录。

默认会从 5001 到 5010 中选择第一个空闲端口；如果 5001 已被占用，会使用后续端口。请在云安全组或防火墙放行实际端口。首次连接会信任这台服务器的指纹，请确认 IP 是你自己的云服务器。
没有选择私钥
用户名必须和云服务器登录窗口保持一致。可以填写登录密码，也可以选择私钥；私钥有口令时在密码栏填写。Mac 或 Windows 已配置 SSH key 时，也可以不选文件并在密码栏输入 //。非 root 密钥用户需有免密 sudo，或在密码栏提供可用的 sudo 密码。
Miru 服务包 推荐
还没有选择文件
请选择从 Miru Releases 下载的服务包，例如 miru-server-v0.2.0-linux-amd64.tar.gz。没有选择文件时，会改用高级选项里的在线镜像地址。
高级选项
如果填写的用户不是系统管理员，Miru 会在需要系统权限时通过 sudo 完成安装；请确认它有 sudo 权限。
已经选择服务包时，这里通常不用改；没有选择服务包时，这里可以填写服务器能直接下载的镜像地址。
