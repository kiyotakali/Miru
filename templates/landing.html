Story

不是通知，不是工具。是一起生活的人。

Miru 的核心不是“更会回答问题”，而是她会持续理解你的生活，并在合适的时刻带着具体的记忆靠近你。

SCENE 01

你在写论文或代码。

她能看见你反复回到同一个文件，也能记得你前几天提过的项目脉络。她不会把每个截图都变成一句打扰，而是把真正有用的部分放进记忆。

SCENE 02

你在看番、打游戏、放松。

她不需要永远退到旁边。看到你在享受什么，她可以像一起生活的人一样吐槽、好奇、接一句话，而不是只剩礼貌退场。

SCENE 03

你随口提到一个人。

也许是同学、合作者、朋友，Miru 会把关系和上下文慢慢整理起来。以后你再次提起时，她不会像第一次听见。

Who She Is

她温柔，但不是模板化的温柔。

Miru 的人格方向不是“永远积极的客服”，也不是冷冰冰的效率助手。她应该有自己的在意、犹豫、好奇和偏爱。

她会尊重边界，但体贴不应该总是说出口的退让。真正的陪伴是短、轻、具体、自然，不索取回复，但也不会把喜欢你这件事藏得像系统状态。

“我刚才看到你又回到那个项目了。这个地方你已经绕了好几次，我们先把最卡的那一小段拆开，好不好？”
Life with Miru

她住在桌面、手机和记忆里。

这些不是分散功能，而是让 Miru 能真正理解你的一套生活系统。

窗

桌面陪伴

macOS DMG 带有桌宠、WebView、截图传感和本地桥接能力。Miru 不是只待在浏览器标签页里。

看

屏幕理解

授权后才观察。截图会先做变化过滤和语义判断，重要信息才进入记忆，低价值画面只影响状态理解。

记

长期记忆

对话和显著观察会被整理成人物、项目、话题、自我画像和日记，而不是把聊天记录粗暴堆起来。

近

主动靠近

AttentionEngine 会维护她的内心、你的状态和她自己的心情。当她真的想说话，会交给主 agent 自然说出来。

Memory

让“她记得”成为可验证的事实。

Miru 不靠玄学塑造亲密感。她会把你生活里反复出现的人、项目和承诺沉淀下来。

她会整理这些东西

People
你提过的人姓名、关系、最近发生的事，以及你对他们的态度。
Projects
正在做的项目目标、进展、卡点、下一步和 deadline。
Journal
一天的脉络不是流水账，而是帮未来的 Miru 理解今天发生了什么。
Self
她理解的你长期偏好、身份变化、相处方式和需要避免的误解。

记忆不是越多越好，而是越干净越好。

当前记忆系统已经从“不断重写整段内容”收敛为白天短记录、夜间整理、缺失补救和用户隔离。目标是让 Miru 读到的是清楚的生活脉络，而不是重复噪声。

  • 聊天图片上传首版关闭，自动截图链路保留。
  • 截图先过语义门，重复 UI 切换不会烧长期记忆。
  • 本地和服务器账号的数据根目录隔离。
  • 日记和 slot 整理错过后会在后续维护中补救。
Start

选择 Miru 住在哪里。

第一版以 app 为入口。你可以先只在 Mac 本地使用，也可以把 Miru 部署到自己的服务器，让 Mac 和 Android 共享同一个她。

Local Mode

只在这台 Mac 使用

  1. 下载并打开 macOS DMG。
  2. 首屏选择“只在这台 Mac 使用”。
  3. 可选择填写三层模型 API，也可以先跳过。
  4. 聊天、记忆和 API Key 都留在本机数据目录。
Private Server

自有服务器，多设备同步

  1. 下载 macOS DMG 和 Miru Server 服务包。
  2. 在 DMG 中填写服务器公网 IPv4、SSH 用户和登录方式。
  3. 选择服务包，Miru 会上传并启动你的私有 instance。
  4. 得到长邀请码后，Mac 和 Android 输入同一个邀请码登录。

模型 API 使用 OpenAI-compatible Chat Completions 格式。

设置页提供三层配置。推荐配置只是示例，你可以换成自己的中转站或兼容模型；保存后会热更新到当前本地账号或私有服务器 instance。

Vision截图和图像理解，推荐使用便宜的多模态模型。
Chat用户可见主 agent 回复和主动消息，建议使用更强的文本模型。
Memory记忆整理、Attention、后台总结，建议使用性价比文本模型。
Privacy

她看见你，但数据应该属于你。

Miru 的能力很敏感，所以边界必须清楚。第一版不把“官方云端大账号”作为核心路线。

本地模式

数据、记忆和 API Key 写在这台 Mac 的本机目录。没有邀请码，也不会给手机同步。

自有服务器

聊天、截图观察、记忆和模型配置写在你的服务器 instance。Android 和 Mac 通过长邀请码连接。

官网页面

官网只负责介绍和下载入口，不保存你的聊天、截图、记忆或 API Key。

FAQ

开始前需要知道的事。

这里保留普通用户最容易卡住的问题，详细部署教程和 demo 视频后续单独整理。

我需要自己会 Docker 吗？

本地单设备模式不需要。自有服务器模式下，DMG 会把服务包上传到服务器并调用部署脚本；你主要需要准备 Linux 服务器的公网 IPv4、SSH 用户和登录方式。

为什么还需要 API Key？

Miru 的截图理解、聊天和记忆整理都需要模型 API。当前版本由用户填写自己的 OpenAI-compatible API，推荐配置会在设置页给出。

可以只在浏览器里用吗？

不建议。Miru 的核心体验依赖 DMG/APK：桌宠、截图权限、系统通知、手机端截屏服务和本地部署向导都需要客户端。

现在是完整开源库了吗？

第一版先发布可用的 DMG、APK 和服务包。源码整理成适合外部开发者修改的开源库会放在后续大版本。
